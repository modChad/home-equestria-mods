# Retired mods

Mods that were merged into another mod or are no longer released. Their source and last pack are
kept here for reference. Nothing in this folder is built (`build_packs.sh` only looks at
`mods/<id>/mod.json`) or listed in `.github/README.md`, and Godot ignores it (`.gdignore`).

# Anonfilly lighter hair

- **Version:** 1.0.0
- **Author:** modChad
- **For:** Anonfilly (NPC) 1.0.0
- **Works on:** desktop and VR

Anonfilly's mane and tail with far fewer triangles, for better framerates on Quest 3. Same look, rig and colours.

| | Before | After |
|---|---|---|
| Mane | 23,744 triangles | 7,936 triangles |
| Tail | 2,016 triangles | 1,280 triangles |

Lower-detail versions are also included, which Godot switches to on its own as she gets further away.

## Install

Put `anonfilly-patch-v1.0.0.pck` in the game's `mods` folder alongside Anonfilly and switch both on in **Settings → Mods**. It only loads with Anonfilly 1.0.0 and switches on and off with her.

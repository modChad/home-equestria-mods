# Balloon Boarding

- **Version:** 1.0.0
- **Made for:** Home: Equestria 0.3.0-maredev
- **Works on:** desktop and VR

Makes it easier to take ponies up in the hot-air balloon.

## What it changes

- **Carry a pony in.** Stand in the balloon and set a pony down in the basket. She stays aboard as a passenger instead of hopping straight back out.
- **Followers who stop short.** A pony following you who gets stuck before the ramp still climbs in after a couple of seconds. Bigger ponies, like Princess Celestia, could stop too far away for the game to let them board.

You need to be in the basket yourself, and it has to be landed with the gate open, the same as the game's own boarding. Ponies still can't wander in on their own.

## Install

Put `balloon-boarding-v1.0.0.pck` in the game's `mods` folder and switch it on in **Settings → Mods**.

## Things to know

- A pony helped in from far away hops the whole way in one go.
- The log notes each time the mod steps in (lines starting `[balloon_boarding]`).
